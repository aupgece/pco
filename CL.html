⬇ Smart import — full semester sheet (courses + sections, one file)
Upload a sheet laid out like a semester course-offering table: a title row per block naming the program(s), the term, and the section(s) — e.g. "BEEV, BEEP, BEEE, BEET– F-26 Section A and B (1st Semester) (8 sections)" or "BEEE, Section A/B (3rd Semester) Fall - 2025 (2) sections" — followed by a header row (S.No, Code, Courses, Prerequisites, Credit Hrs) and the course rows for that block. You can stack as many blocks as you like in one sheet, one after another.

Courses go into the Courses → All tab with the semester noted on the end of the name (e.g. "Calculus & Analytical Geometry (1st Sem)"), credit hours taken from the last number in "(Theory-Lab-Credit)", and the section count set from how many program × section-letter combinations that block's title implies. Sections go into the Classes / Sections tab as PROGRAM-F-YY-LETTER codes (e.g. BEEV-F-26-A, BEEE-F-25-B) built from each block's title.
